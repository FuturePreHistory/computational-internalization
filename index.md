# Computational Internalization

当模型判断成为直觉：计算关系如何进入前反思经验

When Model Judgments Become Intuition: How Computational Relations Enter Pre-reflective Experience

This project examines how machine-maintained computational relations may acquire pre-reflective experiential efficacy through technically designed translation.

## Core concepts

### Category Migration

Category migration describes the transition by which a computational relation moves from functioning primarily as an object of explicit judgment or external signaling to functioning as an organizer of pre-reflective similarity, salience, expectation, and possibilities for action.

[Read the concept note →](concepts/category-migration.html)

### Computational Internalization

Computational internalization describes the condition in which such experiential efficacy has become relatively stable while the computational relations, translation mechanisms, version histories, and modification authority supporting it remain partly external to the subject.

[Read the concept note →](concepts/computational-internalization.html)
